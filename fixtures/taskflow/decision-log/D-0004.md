## Context

NOVA ships two things whose cost grows with subscribers: the fanout loop and the sync channel. The spike measured the fanout on a developer machine; the published envelope (`wiki/sources/selfhost-resource-envelope.md`) describes a 2 vCPU / 4 GB reference box that nobody has yet run either channel against.

CL's proposal is to make a measured run against the reference box a hard gate on general availability, rather than a thing somebody does if there is time.

## Proposal (not yet answered)

Gate GA on a load-harness run against the reference box, failing the release if any threshold below is breached:

| Metric | Proposed threshold | Status |
|---|---|---|
| Notification p95 at 250 subscribers | ≤ 100 ms | provisional |
| Notification p99 at 250 subscribers | ≤ 250 ms | provisional |
| Sync resume after 30-minute gap | ≤ 5 s to converged | provisional |
| App-process peak RSS during run | ≤ 700 MB | from the published envelope |
| Stalled-consumer blast radius | zero effect on other subscribers | from D-0001 condition 2 |

## Open questions

1. **Who owns the gate?** CL proposes SRE owns the run and AR owns the waiver. Not agreed.
2. **Are the thresholds right?** The first three are provisional. They are guesses derived from a spike on different hardware, and the harness (WS-7) has not produced a baseline yet.
3. **Does a breach block or warn at first?** RV argues for warn-only on the first release so the thresholds can be calibrated against reality; CL argues a warn-only gate is not a gate.
4. **Scope:** does the gate cover the accessibility audit findings too, or only performance?

## Why it is still open

The harness that would produce the baseline does not exist yet — WS-7 builds it. Answering this entry before there is a baseline would lock numbers that came from a laptop. The decision is expected to close after the first harness run, which is why WS-7 ships regardless of this entry's status and only `gates.json` is provisional.

## Impact if unresolved

WS-7 ships an instrument with provisional thresholds. If this entry is never answered, GA proceeds with no performance gate at all, which is the outcome CL opened it to prevent.
