# fractal-pr-review

PR-review assistance for FRACTAL repos — gathers a PR's diff and CI state, runs bundled reviewers, and triages findings into a severity-ranked table.

## Skills

| Skill | Purpose |
|-------|---------|
| `pr-assist` | Review a pull request and compound recurring findings into `standards/pr-review-guides/` |

## Install target

Repos with active PR flow.
