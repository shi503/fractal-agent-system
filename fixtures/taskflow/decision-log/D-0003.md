## Context

The offline vault has to reconcile two divergent histories when a client comes back from a network gap. The 2026-08-12 design session settled the *family* — convergent replicated types over operational transform — on the grounds that operational transform puts the correctness burden in a pairwise transform function per op-type pair, and TaskFlow has seven op types with more coming.

That left the library. RV evaluated three candidates against five criteria: bundle size, tombstone garbage collection, whether the clock is exposed, maintainer responsiveness, and whether the unresolved set is enumerable through a supported API.

Input pages: `wiki/sources/offline-sync-approaches.md`, `wiki/raw/2026/08/2026-08-14-RV-crdt-library-eval.md`.

## Answer

**AR-A 2026-08-17 — locked.** Adopt **mergeloom** for vault sync.

mergeloom is the only candidate that satisfies all five criteria without a workaround. It garbage-collects incrementally, so compaction never stalls mid-drag; it exposes a documented clock the sync protocol can carry on the wire instead of inventing a second ordering scheme; and it exposes competing register values as a first-class API.

driftset is 13 kB smaller and rejected on two counts: manual-only compaction, and a last-writer-wins policy that discards the losing value irrecoverably. That is the exact failure the study forbids — silently destroying a user's sentence. weaveline is rejected on bundle size (88 kB) and a 340 ms stop-the-world compaction pause that the keyboard-first positioning cannot absorb.

## The residue rule

This decision carries a rule, not just a dependency. The merge settles structure; it does not settle intent. Card moves, reorders, label changes, assignee changes, due dates, and archive all resolve automatically. A same-field text rewrite does not, and every such case must surface to a review queue with **both candidate values intact**. An implementation that resolves those silently violates this decision even if it uses the right library.

## Impact

- Scopes WS-4 (vault stores mergeloom ops, not raw diffs), WS-5 (clock carried on the wire), and WS-6 (the review queue exists because of the residue rule).
- Adds a 34 kB client bundle dependency; accepted.
- Server holds ops and materialises on read — no per-board document held in process, per the resource envelope.
