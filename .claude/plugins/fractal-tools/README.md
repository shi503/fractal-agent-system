# fractal-tools

General-purpose developer tools for repos running FRACTAL — commit, review, issue, and exploration helpers.

## Skills

| Skill | Purpose |
|-------|---------|
| `create-issue` | Open a tracker issue from the current context, with an offline fallback |
| `create-plan` | Turn a request into an ordered, reviewable implementation plan |
| `deslop` | Strip AI-generated filler and tells out of written material |
| `document` | Generate or refresh documentation for a module or feature |
| `explore` | Map an unfamiliar area of the codebase and report how it fits together |
| `fractal-setup` | Onboard a repo onto FRACTAL: marketplace add, plugin install, router smoke run |
| `peer-review` | Review a change the way a teammate would, before it reaches a reviewer |
| `review` | Pre-landing review of the current diff for correctness and quality |

## Install target

Every repo.
