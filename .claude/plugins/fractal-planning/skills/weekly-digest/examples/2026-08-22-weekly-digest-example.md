## Annotation (not part of the chat output)

**How this example was built:**

1. `wiki/log.md` carries six rows inside the window. Only `ingest` and `synthesis` rows feed
   "New Sources", so the `decision` rows (2026-08-17, 2026-08-21), the `entity-create` row
   (2026-08-19) and the `lint` row (2026-08-22) were excluded — the single `synthesis` row on
   2026-08-20 is the only one that qualifies. The `decision` rows still appear, one section
   lower, sourced from the ledger rather than from the log.

2. Decision Activity was read from the store (`dl list`), filtered on the `updated`
   frontmatter timestamp — not on file modification time. D-0003's `updated` is 2026-08-17
   even though it was created on 2026-08-12, so it lands in this window; D-0001 and D-0002
   were last updated before 2026-08-16 and do not.

3. "Open Items" ignores the date window by design: every `open`, `in_discovery`, or
   `conflicted` entry appears regardless of when it last moved. D-0004 is the corpus's
   deliberately non-terminal entry.

4. Empty sections are reported explicitly. "No active locks" and "Inbox clear" are findings —
   dropping the sections would make a quiet week indistinguishable from a broken scan.

5. The digest is read-only — no file was modified during generation.
