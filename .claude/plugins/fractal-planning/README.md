# fractal-planning

Planning and coordination tools for FRACTAL Architects and Strategists — stakeholder briefs, initiative interviews, meeting digests.

## Skills

| Skill | Purpose |
|-------|---------|
| `decision-ledger-v2` | Capture a decision through a guided interview and write it to the decision ledger |
| `deck` | Turn a document or outline into a presentation deck |
| `gap-analysis` | Audit current state against benchmarks and readiness at a milestone boundary |
| `grounded-meeting-summary` | Summarize a meeting and ground every claim against the deployed code |
| `initiative-interview` | Interview a stakeholder to turn vague intent into a structured initiative record |
| `initiative-sync` | Reconcile an initiative record against execution reality across repos |
| `learning-opportunity` | Pause and teach a concept at escalating levels of depth |
| `meetings-standup-summary` | Turn a standup transcript into a chat-ready per-person digest |
| `sprint-close` | Close a sprint: what shipped, what slipped, what carries over |
| `stakeholder-brief` | Write an audience-tuned brief for an executive, engineering, or product reader |
| `weekly-digest` | Compose a weekly digest from the wiki log, the decision ledger, and the git log |

## Install target

Repos where a human or agent Architect authors BLUEPRINTs.
