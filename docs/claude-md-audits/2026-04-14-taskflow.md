**Why it matters:** canonical templates embedded in CLAUDE.md anchor the agent's style; without them every generated function drifts ([rubric D7](../claude-md-rubric.md), [harness research §3](../research-claude-code-harness.md)).

**After:** Add three more copy-paste-ready templates. Suggested insertion after the existing Server Action Patterns section:

```markdown
## Canonical RSC Query

Copy this shape for every data-loading page:

\`\`\`typescript
// app/(dashboard)/board/[boardId]/page.tsx
import { auth } from "@/lib/auth";
import { getIssuesByBoard } from "@/lib/queries/issues";
import { redirect, notFound } from "next/navigation";

export default async function BoardPage({ params }: { params: { boardId: string } }) {
  // 1. Auth first — no DB access without a session
  const session = await auth();
  if (!session?.user) redirect("/login");

  // 2. Team-scoped query — never pass raw IDs to the client
  const issues = await getIssuesByBoard(params.boardId, session.user.teamId);
  if (!issues) notFound();

  // 3. Render Server Component; pass primitives (not DB types) to client children
  return <Board issues={issues} />;
}
\`\`\`
```

### 3. (Advisory) Dimension 13 — Output Discipline (0/1)

**Why it matters:** internal A/B testing at Anthropic showed ~1.2% output-token reduction by replacing generic "be concise" language with explicit numeric caps ([harness research §10](../research-claude-code-harness.md)). For FRACTAL's many-agent workflows, that compounds.

**Before:** No output-discipline guidance in CLAUDE.md.

**After:** Add a short section near the top (after Role & Persona):

```markdown
## Output Discipline

- **Intermediate status between tool calls:** ≤25 words.
- **Final response:** ≤100 words unless the user explicitly asks for depth.
- **No opening affirmations** ("Great question", "Certainly") — just answer.
- **No trailing summary of what was just done** — the diff or tool result speaks for itself.
- **Reading is not verification. Run it.** Do not mark a workstream COMPLETE without the CI gate passing.
```

The final bullet re-states the Verification Agent rule from the harness research (§12) in a form that directly reinforces the existing CI-gate blockquote.
